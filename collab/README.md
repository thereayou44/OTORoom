# oto-collab

Совместный редактор кода и доска для OTO. Работают между браузерами
по WebRTC data channel — сервер не участвует, Go-код не меняется.

## Из чего состоит

- `src/provider.ts` — Yjs поверх RTCDataChannel: синхронизация, курсоры,
  разбиение больших сообщений на части.
- `src/editor.ts` — CodeMirror 6, C++ и Python, курсоры собеседника.
- `src/board.ts` — доска на canvas: перо, линия, стрелка, прямоугольник,
  эллипс, текст, ластик, цвета, толщина, отмена.
- `src/index.ts` — то, что видит `app.js`: `window.OTO.createCollab(...)`.

## Сборка

```bash
npm install
npm run build        # -> dist/oto-collab.js
```

Файл `dist/oto-collab.js` кладётся рядом с `app.js` в папку `web/`
и подключается тегом script до него.

## Проверка

```bash
npm test
```

Прогоняет типы, тесты синхронизации (сходимость при одновременной правке,
чанкинг, курсоры, отмена) и проверку собранного бандла в jsdom.

## Почему CRDT, а не «кто-то один пишет»

Два курсора и одновременный набор без конфликтов возможны только так.
Yjs гарантирует, что при любом порядке доставки изменений у обоих
получится одинаковый текст — это проверяется тестами 2 и 3.

## Ограничения

- История живёт только пока открыто соединение: закрылись обе вкладки —
  документ пропал. Постоянное хранение потребует сервера.
- Доска рассчитана на холст 1600×900; он вписывается в окно с сохранением
  пропорций, поэтому у собеседников рисунок выглядит одинаково.
- Текст на доске добавляется через `prompt`. Редактирование текста на месте
  не сделано.
